# 服务设计 PWA 原型 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a classroom-usable static PWA prototype for the Service Design course.

**Architecture:** The prototype is a static browser app. Pure calculation and data functions live in `src/app-core.mjs`; the UI in `src/app.js` calls those functions and persists state to `localStorage`.

**Tech Stack:** HTML, CSS, vanilla JavaScript modules, Node.js built-in test runner via `node tests/app-core.test.mjs`, PWA manifest, service worker.
