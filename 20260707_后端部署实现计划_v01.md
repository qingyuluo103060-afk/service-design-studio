**Goal:** Add a deployable lightweight backend so students can access the PWA over a local network or server and share persisted classroom data.

**Architecture:** A dependency-free Node.js HTTP server serves the existing static PWA and exposes JSON APIs. The frontend keeps localStorage fallback but syncs with `/api/state` when the backend is available.

**Tech Stack:** Node.js built-in `http`, `fs/promises`, static HTML/CSS/JS, JSON file persistence.
