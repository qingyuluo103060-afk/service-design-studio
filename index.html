AHP Matrix

AHP 判断矩阵上传与一致性检验

1-9 标度 · CR ≤ 0.10

上传或粘贴成对比较矩阵。第一行/列为需求名称，矩阵数值支持 1、3、5、7、9 或小数。系统会输出权重、λmax、CI、CR 和是否通过一致性检验。

未上传矩阵时，系统会根据当前需求的重要度/满意度生成课堂演示权重；上传后以真实矩阵为准。

TRIZ Worksheet

TRIZ 矛盾分析与发明原理转化

关键需求 → 服务矛盾 → 方案卡
先从 Kano/AHP 得到关键需求，再识别“想改善什么”和“可能恶化什么”，最后把 TRIZ 原理转译成服务触点方案。

TOPSIS Matrix

AHP-TOPSIS 决策矩阵上传与过程表

归一化 · 加权 · 贴近度

上传备选方案评价矩阵。表头格式建议：方案,创新性,可行性,服务质量,风险；风险为成本型指标，其他默认为效益型指标。权重可来自 AHP。

未上传矩阵时，使用方案卡片中的创新性、可行性、服务质量和风险评分进行排序。
